## Ordering checklist for greenhouse fixing hardware

- Replacements: send product names or photos from the existing structure.
- New structures: share the drawing, pipe size, sheet or net type and installation details before ordering hardware.
- Dealers: ask for fast-moving clamps, grippers, wire and curtain accessories as a stock bundle.
